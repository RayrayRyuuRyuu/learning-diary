# 학습·성장 다이어리 (웹앱)

초등 학습 기록을 날짜별로 남기는 **개인용** 학습 다이어리 웹앱입니다. 영역(흘려듣기·집중듣기·영어책읽기·한글책읽기·학습·정신건강·성장일기 등)별로 공부 시간과 사진을 기록하고, 기간별로 모아 보거나 주간 결과분석·PDF 저장을 할 수 있습니다.

**사용 주소:** https://rayrayryuuryuu.github.io/learning-diary/

## 특징

- 빌드 도구나 외부 라이브러리 없이 `index.html` 한 파일로 동작합니다.
- **이메일 로그인**으로 시작합니다. 로그인하기 전에는 로그인 화면만 보이고, 기록은 로그인한 본인에게만 열립니다.
- 기록과 사진은 클라우드(비공개 저장소)에 **본인 계정으로만** 저장되고, 폰·컴퓨터가 자동으로 동기화됩니다.
- 기기에도 함께 저장되어 인터넷이 없어도 열람·작성할 수 있고, 다시 연결되면 클라우드와 합쳐집니다.
- `⚙️ → 백업`에서 `전체 내보내기`(모든 기록·사진)나 **기간을 골라 내보내기**(`전체` / `이번 달` / `지난 달` / `기간 지정`)로 JSON 파일을 저장합니다. 기간을 고르면 그 기간 기록과 **그 기록이 쓰는 사진만** 담아 파일이 가벼워지고(사진을 다 담으므로 복원은 그대로), 내보내기 전에 기록 일수·사진 장수를 미리 보여 줍니다. `불러오기`는 지금 기록을 지우지 않고 **파일에 든 날짜만 병합**합니다. 같은 날짜는 파일 내용으로 바뀌고, 책장·영역은 합쳐지고, 이미 있는 사진은 건드리지 않습니다.
- 비밀번호를 잊으면 로그인 화면의 `비밀번호를 잊으셨나요?`로 재설정 메일을 받을 수 있습니다.
- 설정에서 **모든 기기에서 로그아웃**으로 다른 기기의 세션을 한 번에 끊을 수 있습니다.
- 영역 추가·이름 변경·순서 변경, 기간별 모아보기, 전체 검색, 사진 첨부, 주간 결과분석, PDF 저장·전체 복사 기능이 들어 있습니다.
- 영역마다 필요한 버튼만 보입니다. `영어 > 흘려듣기`는 `🎬 포스터`·`▶️ 유튜브`·`📷 사진`, 책읽기(영어책읽기·한글책읽기)는 `📚 책 표지`·`📷 사진`, `정신건강`은 `▶️ 유튜브`·`📷 사진`, 그 밖의 영역은 `📷 사진`만 나옵니다.
- `🎬 포스터`는 영화·시리즈(넷플릭스·디즈니+ 등) 포스터를, `📚 책 표지`는 책 표지를 찾아 사진처럼 붙입니다. (책: **알라딘** 검색이 1순위 — 국내 어린이책과 영어 원서 표지가 잘 나옵니다. 알라딘에서 못 찾았을 때만 Google 도서·Open Library로 대체 / 영화·시리즈: 위키백과·TVMaze)
- 표지·포스터·유튜브 썸네일은 **작은 썸네일**로 들어가 본문에 여러 개를 붙이면 한 줄에 나란히 보입니다(누르면 크게 보기). `📷 사진`으로 직접 올린 사진만 크게 한 장씩 보입니다.
- `▶️ 유튜브`는 유튜브 링크(youtube.com/watch·youtu.be·shorts·live)를 붙여넣으면 썸네일과 영상 제목을 미리 보여 주고, `추가하기`로 그 자리에 사진처럼 넣습니다.
- 최근에 붙인 표지·포스터는 **탭별로 따로** 남습니다. `📚 책` 탭에서는 최근 책 표지, `🎬 영화·시리즈` 탭에서는 최근 포스터만 나오고(각 최대 9개), 검색 결과 **아래**에 놓여 키보드가 올라와도 검색 결과를 가리지 않습니다. 검색 없이 눌러서 바로 다시 붙일 수 있습니다.
- `📚 책장` 탭은 위에서 `📚 책` / `🎬 영상`으로 나뉩니다. `📚 책`은 읽은 책을 표지 중심 **3열** 그리드로 촘촘히 보여 주고(총 권수·누적 횟수·읽은 날짜·`＋1 오늘`), 쓰기에서 책 표지를 붙이면 그날 날짜로 자동 기록됩니다. `🎬 영상`은 다이어리에 붙인 영화·시리즈 포스터와 유튜브 썸네일을 **채널명**과 함께 모아 봅니다. (클라우드 동기화 포함)
- 쓰기 화면의 각 영역은 글·사진 영역 높이가 **300px로 고정**되고 그 안에서 스크롤돼, 한 영역에 글과 사진을 많이 넣어도 아래 영역까지 쉽게 내려가며 쓸 수 있습니다.
- 학습노트 보기·기간 모아보기·PDF에서 `[J1]` `[JK3]` 같은 잠수네 책 레벨 태그는 **한 권씩 줄을 바꿔** 보여 줍니다(저장된 글은 그대로).
- 폰의 **뒤로가기**를 누르면 앱이 바로 꺼지지 않고 열린 창을 닫고 이전 탭·이전 날짜로 돌아갑니다. 첫 화면에서는 ‘한 번 더 누르면 앱을 닫아요’라고 알려 줍니다.
- 입력창을 누르면 자판이 올라오면서 **입력창이 자판 위로 자동으로** 올라옵니다(`interactive-widget=resizes-content` + visualViewport 감지).
- 사진은 `📍 글 커서 위치에 넣기`로 본문 원하는 자리에 넣을 수 있고, 본문에 넣지 않은 사진은 글 아래에 차례로 붙습니다.
- 시간 입력의 `+5m` `+15m` `+30m` `+1h` 버튼은 지금 적힌 시간에 **더해집니다**(예: 10분에서 `+30m` → 40분, 한 번 더 → 1시간 10분). `안함`은 0분으로 되돌립니다.
- 휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다. (전용 다람쥐 아이콘·웹앱 매니페스트 포함)

## 사용법

1. 위 주소를 크롬이나 삼성 인터넷으로 엽니다.
2. 처음이면 **회원가입** 탭에서 이메일과 비밀번호(6자 이상)를 넣습니다. 다음부터는 같은 이메일로 로그인하면 됩니다.
3. `⚙️`에서 이름·학년을 저장하고, 원하는 영역을 골라 기록을 남깁니다.
4. 가끔 `백업 내보내기`로 백업 파일을 따로 보관해 두면 더 안전합니다.

## 보안

- 데이터베이스는 **행 수준 보안(RLS)** 이 켜져 있어, 로그인한 사용자가 자기 행만 읽고 쓸 수 있습니다.
- 사진은 비공개 버킷에 저장되고, 짧은 시간만 유효한 서명 URL로만 표시됩니다.
- 코드에 들어 있는 것은 공개용 클라이언트 키(anon/publishable)뿐이며, 서버 비밀 키는 없습니다.

이 저장소에는 앱 코드만 있습니다. 특정인의 기록·개인정보는 저장소에 포함되어 있지 않습니다.
